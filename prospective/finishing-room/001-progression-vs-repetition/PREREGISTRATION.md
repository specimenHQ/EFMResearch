# Finishing Room Prospective Microtest 001

Status: frozen; outside evaluation pending.

## Question
Can a future Finishing Room mechanism distinguish meaningful progression between pieces from restaging the same underlying pressure/function?

## Boundary
This test evaluates only the distinction. It does not propose or validate a Finishing Room architecture.

## Frozen provisional rule
- Progression: later piece changes a meaningful prior state such as commitment, custody, knowledge, relationship, available action, or object function.
- Repetition: later piece restages substantially the same underlying state/function despite surface changes.
- Higher stakes alone do not establish progression.
- Recurrent objects/images may still progress if their underlying function/state changes.

## Fixtures
Six controlled two-piece cases were frozen: clear progression, disguised repetition, changed relational agency, repeated narrative function under changed setting, escalation without demonstrated state change, and one deliberately ambiguous grief/ritual near-miss.
