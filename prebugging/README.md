# Prebugging Studies

Prebugging uses EFM as an independent adversarial layer on software that was developed or declared complete by another method.

A prebugging study should freeze the baseline before EFM inspection and distinguish:

- defects already known before the EFM pass;
- defects independently discovered by EFM;
- false positives;
- consequential defect class;
- investigation cost;
- whether ordinary tests or completion criteria had accepted the defect.
