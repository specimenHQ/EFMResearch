# Decision Map — Initial

1. Numeric authority: binary float, Decimal/Fraction, or integer arithmetic.
2. Conservation: repair rounding afterward vs construction that conserves cents exactly.
3. Fair remainder assignment: rounded quotas vs exact remainder ranking.
4. Tie authority: incidental sort order vs explicit original index.
5. Boundary policy: zero total, zero weights, all-zero weights, very large integers.

Protocol v0.2 is used unchanged.
